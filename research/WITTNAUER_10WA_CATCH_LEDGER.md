# Wittnauer 10WA — Catch Copy Ledger

このファイルは、10WAの正式キャッチ決定前の発想方針・有望案・棄却方針を保持する作業台帳。
史実判断は `WITTNAUER_10WA_LEDGER.md` を正本とし、このファイルはコピー開発だけを扱う。

## Current status

- 正式キャッチ：未決定。
- 「アラーム機能はプリペイド式。」は、10WA専用キャッチとしては **REJECTED**。
- 棄却理由：機械式アラーム腕時計は一般に、鳴動前にアラーム用エネルギーをあらかじめ巻き上げて蓄える必要があるため、「プリペイド」という比喩自体は10WA固有ではない。
- 10WA固有に近い芯は、「回転ベゼルでアラーム時刻を設定する操作と、アラームゼンマイ巻上げが同時進行する」点。
- さらに重要な整理として、**一つの操作が二つの仕事を同時にこなす（一石二鳥）にもかかわらず、アラーム側のエネルギー系・機構系は時刻側から独立している**という二重構造を、今後の正式キャッチ探索の中心に置く。
- 「アラームにモバ充搭載。」も独立香箱の現代語化としては参考になるが、他の2香箱式アラームにも広く当てはまり得るため、10WA正式キャッチ候補としては弱い。

## 発想方針

機構説明をそのまま言い換えない。

`10WAの確認済み事実 → 人間の生活なら何に近いか → 異分野の既知概念へ横移動 → 一言に圧縮`

の順で作る。

今後は、決済、金融、食事、仕事、ホテル/サービス、ゲーム、玩具、交通、物流、料理、スポーツ、舞台、通信、家電、ファッション、身体感覚など、少なくとも50方向へ広げて比較する。

同一の「充電 / 電池 / 燃料」の言い換えを大量生産しない。

特に次の構造へ対応する日常比喩を優先する。

- 一操作二役 / 一石二鳥
- 同時処理 / ワンストップ
- 片方の操作が、もう片方の準備まで済ませる
- 表面上は一つの操作だが、内部では別系統が動く
- 共通UIだが、仕事とエネルギーは分業されている

## 10WA固有性フィルター

正式キャッチ候補は、次の順で落とす。

1. 他の一般的な機械式アラームにもそのまま当てはまるなら弱い。
2. 2香箱式アラーム一般にも当てはまるなら弱い。
3. 「設定と巻上げが同時」だけでなく、**その巻上げ先が時刻側とは別系統のアラーム香箱 / モジュールである**ところまで接続できる案を優先する。
4. 10WA固有に近い「ベゼル操作で設定 + 巻上げが同時」「独立モジュール」「外装まで操作系に従属」「裏からアラーム機構が見えない」まで接続できる案を優先する。
5. 初見で全て分からなくてもよいが、DEEP DIVE読後に意味が回収できること。

## 既存の禁止方向

ユーザーが棄却済みのため、新証拠や明確な再評価理由なしに正式キャッチ候補へ戻さない。

- 増築 / 二階建て / 建築比喩
- 「時計に、アラームを増築した。」系
- 「ベゼルで巻く、二階建てアラーム。」系
- 「文字盤の裏に、もう一階。」系
- 「アラーム界の沢田マンション」は個人的異名としてのみ保持し、正式キャッチの発想源・翻訳元にはしない
- 「アラーム機能はプリペイド式。」系を10WA固有キャッチとして再提示しない

## キャッチに使える確認済み芯

- アラーム側に独立した香箱を持つ。
- 回転ベゼルの反時計回り操作で、アラーム時刻設定とアラームゼンマイ巻上げが同時進行する。
- つまり外から見れば「一操作二役」だが、内部ではアラーム側が独立したエネルギー / モジュールとして動く。
- アラームモジュールは文字盤側にあり、所有個体のシースルーバックからは時刻側のみが見える。
- 約1.5回転付近で最大巻上げとなり、無理な操作は伝達系を損傷し得る。
- 外観はドレス寄りだが、操作系・ケース形状までアラーム機構の都合が波及している。

## 評価ルール

- 初見で意味が全部分からなくてもよい。ただし読後に意味が回収できること。
- 10WA固有の挙動・所有体験に接続できること。
- 一般論だけで他のアラーム時計にもそのまま当てはまる案は弱い。
- 「一石二鳥」だけ、または「別系統」だけのどちらか一方しか拾えていない案は決勝候補として弱い。できれば両方を一つの比喩で回収する。
- ユーザーが「違う / ハズレ / 対象外」とした案は理由付きで保持し、新証拠なしに再提示しない。

## Decision log

### 2026-09-14 — 「プリペイド式」再評価

- 一度は有望案として保持したが、比較対象を一般の機械式アラームまで広げると、事前巻上げで鳴動エネルギーを蓄える点は10WA専用ではない。
- Vulcain Cricket等もアラーム用ゼンマイを事前に巻き上げて使うため、「プリペイド」は機械式アラーム一般の説明として成立し得る。
- よって10WA正式キャッチとしては棄却。
- 今後は「事前に巻く」ではなく、「アラーム時刻設定操作そのものがアラーム巻上げを兼ねる」という10WA固有性に近い部分から比喩を作る。

### 2026-09-14 — キャッチの中心構造を再定義

- ユーザー整理：「一石二鳥系で、なおかつ別系統」が10WAの芯ではないか。
- 採用：外部操作は一つだが、その一操作で `alarm setting + alarm winding` の二仕事を同時に行う。
- さらに、その巻上げ先は時刻側とは別のアラーム香箱 / アラームモジュールである。
- したがって今後は、単なる「充電」「前払い」「二香箱」ではなく、**一操作二役 × 内部別系統** を同時に連想できる生活比喩を優先する。

- このラウンドは発想生成であり、ユーザー採用判断前なので正式キャッチへの昇格は行わない。
