# Wittnauer 10WA — Deep Dive Editorial Decisions — 2026-09-15

Status: ACTIVE EDITORIAL RECORD / NOT PUBLISHED

## 目的

10WAのDeep Diveを、調査報告書でも要約記事でもなく、既存VINTAGE ALARMの深掘り本文と同じ密度・調子へ揃える。

比較対象は現行の `basis-alarm.md`、`cyma-time-o-vox.md`、`pierce-duofon.md`。これらは章数自体よりも、ひとつの機構について「何が起きるか → なぜそうなるか → 実機・資料ではどう確認できるか」までつないでいる。10WAも同じ考え方で整える。

## 採用する構成

6章に固定する。

1. `Wittnauerとは`
2. `Wittnauer最初のアラーム、10WA`
3. `Cal.10WAの中身`
4. `1952年の特許と量産10WA`
5. `独自機構のすぐ後に`
6. `10WAのバリエーション`

01・05・06は比較的軽く、02・03・04を厚くする。章数を増やして論点を細切れにしない。

## 棄却した構成・理由

- 8章構成：研究報告書化しすぎるため棄却。
- 5章の初稿：Wittnauer自体の説明とバリエーションが欠けるため棄却。
- 6章の過圧縮稿：既存Basis / Cyma / Pierceより説明密度が薄く、機構の因果が途中で切れるため棄却。
- `特許` と `満巻き後の逃げ` を別章にする案：同じ比較の中で読む方が自然なため統合。
- `その後はASへ` という見出し：一直線の技術移行・因果を暗示するため棄却。

## 日本語監査ルール

- 研究メモの判定語を本文へ持ち込まない。`STRONG / CONFLICT / OPEN` 等は内部記録に留める。
- `技術資料は〜を強く示す`、`現時点の結論は`、`構造的一致` のような翻訳調・報告書調を避ける。
- 名詞を詰め込みすぎず、実際の動作を動詞で説明する。
- `真正のモジュール式キャリバー` のような不自然な直訳は使わない。必要なら「時刻機構の文字盤側に、独立したアラーム機構を重ねる」と具体的に書く。
- 不明点は「分からない」「資料が食い違う」と自然な日本語で示す。
- `よく似ている。でも、同じではない。` は短く、10WAの特許比較を要約する文として採用する。

## 内容の取捨選択

### 残す

- Wittnauerの輸入・商品化企業としての背景。ただし10WA採用理由へ直結させない。
- 10WAがWittnauer最初のアラーム腕時計とされること。
- ベゼル反時計回りでアラーム時刻設定とアラームゼンマイ巻上げを同時に行う操作。
- 2香箱、文字盤側の独立アラーム機構。
- Horlbeck / BeitlのLonginesベース記述。
- Marshallの10WA / 10S主要部品共有と、AWIの10S = AS1200対応。両者の資料衝突は消さない。
- CH304088Aの1952年出願、Marcel Bliss名義、10WAに近いベゼル巻上げ＋設定構造。
- CH304088AとWittnauerを直接結ぶ譲渡・ライセンス等の資料が未確認であること。
- 特許のslipping bridleと、量産10WAの満巻き時ハードストップの差。
- 1955年のAS1475搭載Wittnauerが記録されること。ただし10WA終了理由との因果は書かない。
- SS / 10K GOLD FILLED、銀色系 / 黒文字盤、Ref.1215 / 1216 / 1216Aの現存例、Longines銘10WAをバリエーション章へ整理。

### 書かない / 広げない

- `AS1475が登場したから10WAが廃止された`。
- `10WAは壊れやすかったから短命だった`。
- `CH304088Aは10WAの特許`、`Wittnauerがライセンスした`。
- `Wittnauerがslipping bridleを省いた`。
- `国内販売個体はほぼ金張り`。国内で金張り例が複数確認できる、まで。
- Marcel Bliss / Busgaの人物史。
- X31xx全パーツ系譜。
- シリアル完全年表。

## OWNER'S NOTEとの役割分担

「所有するアラーム腕時計の中で、もっとも思い入れのある一本」という個人的な一文はDeep Dive本文へ入れない。入れる場合はOWNER'S NOTE側の短い一文として扱う。

Deep Diveでは従来どおり時計を主語にする。

## 完成密度

既存ページとの比較から、6章・約20〜25段落を目安とする。特に02・03・04は、事実を列挙するだけでなく、操作・構造・資料の関係が一続きで読める密度を確保する。

## 競合比較を踏まえた位置づけ

2026-09-15時点の競合比較では、10WAの基本的な操作・モジュール構造・2香箱・ベゼルによる設定＋巻上げ自体は、Cinci Watches、日本のOH記事、Hodinkee、フォーラム、販売店等ですでに広く説明されている。

したがって、VINTAGE ALARMの10WA記事は「珍しい10WAを紹介すること」自体を存在理由にしない。

### 競合と重なる部分

- 10WAの基本操作。
- ベゼルでアラーム時刻設定と巻上げを行うこと。
- 2香箱・モジュール式という基本構造。
- SS / 金張り / 黒文字盤など個別バリエーションの存在。
- Longinesベース説そのもの。
- Longinesベース説への疑義そのもの。

これらはVA独自発見として扱わない。

### VAで残す価値が高い部分

1. **Longines説とAS1200系資料の正面衝突**
   - Horlbeck / Beitl等のLonginesベース記述をそのまま残す。
   - Marshallで10WAと10Sの主要時刻側部品共有を示す。
   - AWIで10S = AS1200を確認する。
   - どちらかへ安易に一本化せず、資料衝突自体を記事の論点にする。

2. **CH304088Aと量産10WAの比較**
   - 1952年出願、Marcel Bliss名義。
   - 文字盤側の独立アラーム機構、ベゼル巻上げ、同じベゼルでの設定という共通点。
   - 特許のslipping bridleと、量産10WAの満巻き時ハードストップという差。
   - Wittnauerとの直接接続資料が未確認であること。
   - 「よく似ている。でも、同じではない。」を記事の要約軸とする。

3. **バリエーションの横断整理**
   - 個々の仕様は既出でも、Ref.1215 / 1216 / 1216A、SS / 10K GOLD FILLED、銀色系 / 黒文字盤、Longines銘を一ページで出典付き整理することに価値を置く。

### 章ごとの編集優先度

- 01 `Wittnauerとは`：最小限。企業史を長くしない。
- 02 `Wittnauer最初のアラーム、10WA`：基本操作は既出情報なので、実機体験・操作と内部構造をつなぐ範囲に留める。
- 03 `Cal.10WAの中身`：**記事の主軸。削らない。**
- 04 `1952年の特許と量産10WA`：**記事の主軸。最重要。削らない。**
- 05 `独自機構のすぐ後に`：短く。AS採用との因果を作らない。
- 06 `10WAのバリエーション`：資料集として残す。個別仕様を世界初情報のように扱わない。

## 競合優位を本文で誇張しない

競合検索で「主要記事ではCH304088A比較が見つからなかった」ことは、編集上の価値判断には使える。ただし、Web全体に先行例が存在しないことの証明ではない。

したがって本文で、

- `初めて明らかにした`
- `世界初`
- `誰も気づいていなかった`
- `他の記事にはない`

等の独自性主張は行わない。

VAの価値は、既存情報を否定して目立つことではなく、**資料を並べ直し、どこまで確かで、どこから不明かを見える形にすること**に置く。
