# Modern De Luxe — Completion Definition & Execution Plan

Status: ACTIVE research protocol
Scope: PR #135 research branch only. No public-site change.

2026-10-03 strategy reset: Council V3 / 7 (宮廷道化師) identified an earlier untested premise: clock/watch, travel-clock, and lighter uses of `Modern De Luxe` have not yet been proven to share one brand/operator. The user adopted the reset. Cross-category Hirota/H.M.C. evidence must therefore not support clock attribution unless that common-operator bridge is first established.

## 1. Completion definition

This investigation is not complete merely because Hirota becomes plausible. It is complete at one of two terminal states.

### COMPLETE-A — identity / commercial chain resolved

Reach this state only when at least one contemporaneous or independently attributable source directly connects a `Modern De Luxe` clock/watch to a named commercial actor in one of these roles:

- manufacturer / assembler
- trademark owner / brand operator
- exporter
- wholesaler / distributor
- promotional-goods supplier / corporate-gift contractor
- warranty / service entity

The source must contain the clock/watch identity and the named actor in the same evidentiary chain. A seller attribution, visual similarity, jewel count, co-listing, later collector caption, or name resemblance is insufficient by itself.

Then separately classify whether that actor is Hirota / H.M.C. / Modern Royal / another entity. Do not force the result toward Hirota.

### COMPLETE-B — accessible evidence exhausted without identity resolution

Reach this state only after all five gates below have been executed to their defined stopping point and no direct clock-to-company bridge is recovered. The result must then state exactly what remains blocked behind non-public / unscanned / physical sources rather than continue cyclic web searching.

This is a legitimate completion state: `unresolved with bounded evidence`, not a failed search.

## 2. Five gates and pass conditions

### G1 CLOCK → COMPANY
PASS: clock/watch + named commercial actor in one attributable source chain.
Current: OPEN.

### G2 TRADEMARK → OWNER
PASS: contemporaneous trademark/register/catalog evidence assigning `MODERN`, `Modern De Luxe`, or the relevant crest to a named owner/operator.
Current: OPEN; digitized books identified but body text not yet recovered in this environment.

### G3 H.M.C. → ENTITY
PASS: `H.M.C.CO., TOKYO` tied to a legal/company identity by address, officer, trademark, patent, directory, export record, company document, or equivalent direct evidence.
Current: OPEN/HOLD. `MODERN` ↔ `H.M.C.CO., TOKYO` is physically evidenced; `H.M.C. = Hirota` is not yet directly proven.

### G4 CLOCK → DATE
PASS: at least one Modern De Luxe clock/watch independently dated by contemporaneous documentation or a corporate anniversary/event whose date is itself primary-sourced.
Current: PASS for a bounded 1975-era anchor, not manufacture date. A Yahoo Auctions object is titled `MODERN DE LUXE ALARM / 創業20周年 / 1兆円達成記念 / 農協の共済 / 贈 福岡県共済連`. Independently, library/CiNii records show the issuer 福岡県共済農業協同組合連合会 published its own `福岡県農協共済二十年史` in 1975 (福岡県立図書館 gives 1975.6; 福岡市総合図書館 gives the same title/issuer; CiNii records 1975). This independently anchors the commemorative event to the 1975 twenty-year milestone. Treat this as an event/provenance anchor only: it does not prove clock manufacture in 1975, supplier identity, or a pre-1971 date.

### G5 PROMOTIONAL GOODS / DISTRIBUTION → COMPANY
PASS: Modern De Luxe promotional product + supplier/operator identity, or an independently documented distribution chain that can be tested against the clock line.
Current: OPEN; high priority. The Fukuoka and Mitsubishi commemorative clocks strengthen the promotional-goods corpus, but neither currently names the supplier/operator.

## 3. Search controls

Do not count these as progress unless new primary/direct evidence appears:

- repeating Modern Royal corporate-history searches
- repeating Modern Feudor = Hirota confirmation
- collecting ordinary naked Modern De Luxe clocks
- Tokyo Tokei / 2-jewel / case-shape similarity attribution
- seller decade labels
- same-seller or same-lot inference
- generic `Modern De Luxe` hits in unrelated product categories

Every research run must end with one of:

- MATERIAL PROGRESS — a gate moved
- CONTRADICTION — an adopted/held claim weakened or split
- ACCESS ADVANCE — source body / archival access path materially advanced
- NO MATERIAL PROGRESS — no gate moved

## 4. Execution order

1. Promotional-goods bridge: exact-name Modern De Luxe lighters and H.M.C./Modernlite promotional products; prioritize markings, boxes, catalogs, institutional collections, and corporate-client records.
2. H.M.C. entity fingerprint: company/address/officer/patent/trademark/export-directory evidence.
3. Trademark body text: 1959/1965 trademark references and related registries; bibliographic existence alone does not count.
4. Customer reverse path: Mitsubishi Nagoya Works and Fukuoka mutual-aid commemorative clocks; seek procurement, anniversary, gift, supplier, or internal-history evidence. The Fukuoka 20-year milestone is now independently anchored to 1975; supplier remains open.
5. Clock-industry body text: 1960/1965/1968 clock dictionaries and 1973/74 chronology/index.

Stop a branch when it returns only already-known marketplace copies or unsupported seller dating.

## 5. Fact-check protocol

Before promoting a claim:

1. Separate object-visible markings from seller metadata.
2. Prefer institutional/official/contemporaneous evidence over marketplace prose.
3. For marketplace evidence, record only what the photographs/title directly establish; do not inherit seller dates or manufacturer attributions without support.
4. Seek a second independent source for any bridge that changes the central model.
5. Explicitly test the strongest alternative explanation: coincidental/common trade name, OEM, distributor branding, later replacement movement, or unrelated company.
6. Keep `Hirota manufactured`, `Hirota sold`, `Hirota group`, `H.M.C.`, and `Modern Royal` as separate propositions.

## 6. Current terminal question

The investigation should now answer, in this order:

1. Who commercially operated / supplied Modern De Luxe clocks?
2. Was that actor connected to H.M.C. / Hirota / Modern Royal, or not?
3. Only after 1–2: who actually manufactured the clock movement / finished clock?

Movement-maker identification is downstream, not the primary completion criterion.
