# VINTAGE ALARM — External Reference Outreach

更新日: 2026-09-15

## 最優先原則

この施策は**SEO営業・相互リンク営業ではない**。

1. **SEO営業・相互リンク営業にはしない。**
   - 被リンク数、順位、AI引用数そのものを目的にしない。
   - `リンクしてください`、`相互リンクしませんか`、`AIに引用されています` を営業理由にしない。

2. **相手の不足を埋める資料・データ・実機観察を先に提供する。**
   - 一次資料、専門文献、ムーブメント情報、所有実機の写真・操作・鳴動・観察記録など、相手の読者やデータベースに実質的な利益があるものを先に出す。
   - VINTAGE ALARMへのリンクは、その補完資料をさらに追うために自然に必要な場合だけ提案する。

3. **最終的な価値は、時計を知らなかった人でも必要な情報まで掘れる経路を増やすこと。**
   - どの入口から来ても、必要に応じて**実機の存在、操作、音、機構、資料差**まで確認できる状態を目指す。
   - 外部DB、Wiki、記事、研究媒体、検索、AIなどを別々の入口として扱い、VINTAGE ALARMだけに閉じ込めない。

この3点は、外部参照施策を評価するときの上位原則とする。`LINKED` や順位上昇が起きても、この目的から外れる施策は成功扱いしない。

## 目的

VINTAGE ALARMが持つ一次資料・専門文献・所有実機・機構整理を、既存の時計資料サイトや編集媒体にとって実際に使える補完資料として提示し、その結果として、知りたい人が外部のどの入口からでも必要な深度まで辿れる経路を増やす。

外部参照は検索・AI発見性に寄与する可能性があるが、リンク獲得自体を権威性やAIO成功の証拠として扱わない。

## 基本ルール

- `リンクしてください` から始めない。
- 相手ページの不足を補う資料・一次資料・実機観察を先に提示する。
- AIO、AI引用、SEO目的、相互リンクを営業文句にしない。
- 1回の接触で複数ページへの掲載を要求しない。
- まず1モデル / 1キャリバー / 1論点に絞る。
- VINTAGE ALARMの本文に誤り候補がある状態で営業しない。既知の誤り・資料差は先に修正履歴へ残す。
- 外部掲載されたことを、その内容の正確性保証として逆輸入しない。
- 第三者サイト側の編集方針・ライセンス・投稿ルールを優先する。

## 接触前の最低条件

1. 対象WATCHの本文・出典・RESEARCH NOTE / REVISIONを最新化
2. 先方へ提示する一次資料 / 専門資料の該当箇所を特定
3. VINTAGE ALARMにしかない価値を1文で説明可能にする
4. 現行 `https://vintagealarm.github.io/` のURLだけを使う
5. 旧hostを営業文・資料に混ぜない

## 成功判定

段階を分ける。

1. `CONTACTED` — 資料を送った
2. `ACKNOWLEDGED` — 相手が受領・返信した
3. `USED` — 相手側本文・DB更新に資料が使われた
4. `LINKED` — VINTAGE ALARM現行URLが参考資料として掲載された
5. `REFERRED VISIT` — その外部参照からサイト来訪が観測された
6. `DISCOVERY EFFECT` — Search / External AIで現行URL発見性の変化が観測された

`LINKED` を即 `DISCOVERY EFFECT` と呼ばない。

NAWCC等の外部研究媒体は `PUBLISHED / REVIEWED` を別指標として持ち、単なるLINKEDと同一視しない。
